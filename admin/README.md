# 林夕的小站 · 专属后台

一个只属于你自己的网站管理面板。**零依赖**（只用 Node 内置模块）、**只监听本机**、**改动前自动备份**。

```bash
npm run admin
```

然后浏览器打开 <http://127.0.0.1:4322>。或者直接**双击项目里的 `打开后台.cmd`**（它会自己检查环境、启动服务、打开浏览器）。

- **第一次**打开会让你设一个密码（至少 6 位）
- 密码存在 `.admin/auth.json`，已在 `.gitignore` 里，**不会进 GitHub**
- 忘了密码：删掉 `.admin/auth.json`，重新打开就会让你重设

## 能做什么

| 页面 | 能力 |
| --- | --- |
| **仪表盘** | 笔记 / 照片 / 视频 / 友链数量、草稿提醒、最近改动、相册分布、常用操作快捷键 |
| **笔记** | 列表搜索 + 分类筛选 + 只看草稿；编辑器带 frontmatter 表单、**实时预览**（和线上同一套渲染器）；支持新建 / 改名 / 删除 / 草稿开关 / 置顶 / 「Ctrl+S 保存」 |
| **相册** | 拖拽或点选上传（手机直接开相册）；自动压缩 WebP、丢 EXIF、最长边 2000px；点图改标题 / 描述 / 标签 / 分类 |
| **视频** | 粘一条抖音 / B站 / YouTube 链接即可添加（自动识别类型、提取 id）；列表里编辑 / 删除 |
| **友链** | 表单增删改：站名、网址、简介、头像、标签、认识时间、置顶、招募位 |
| **站点信息** | `config.js` 的字段全部变成表单（站点网址、品牌名、首页文案、个人页、友链入口、页脚…） |
| **配色外观** | 色板 + 取色器实时改 `:root` 变量，**带预览区**，满意才保存 |
| **内容体检** | 找未来日期、空正文、没分类、同名笔记、断掉的双链、找不到的插图；还能**联网核查外站图片是否真的打得开** |
| **构建发布** | 一键跑 `npm run sync && astro build`，**实时日志**、构建历史、打开 dist 文件夹 |

## 它怎么保证不把你的站改坏

改你的文件这件事本身有风险，所以做了五层：

1. **只监听 `127.0.0.1`** —— 局域网和外网都连不上，不用配防火墙
2. **写入白名单** —— 只有这些东西能被改：

   ```
   blog/                 你的笔记
   img/                  你的图片
   src/data/             config.js / videos.js / links.js / photo-meta.js
   public/media/         压缩后的图 / 封面 / 笔记插图
   public/assets/css/    配色
   ```

   `src/layouts/`、`astro.config.mjs` 这类源码**一律只读**
3. **路径越界会被拒绝** —— `../`、绝对路径、盘符路径、含 `\0` 的路径全部拦掉
4. **改 `.js` 数据文件前先做语法检查** —— 生成的新内容先写到临时文件用 `node --check` 验一遍，
   **语法不过就放弃写入**，你的文件一个字节都不动。（这条已经救过好几次场了。）
5. **每次写入前自动备份** —— 旧版本存到 `.admin/backups/`，保留最近 30 份 / 60 天，超量自动清理

### 另外，改笔记时保证「最小 diff」

1. **字段顺序照抄原文件** —— 你在 Obsidian 里怎么排的，回写就怎么排
2. **数组写法保持不变** —— 块状 `- 项` 还是行内 `[a, b]`，跟着原文走
3. **没碰过的字段一个都不动** —— 包括 `cssclasses` 这类后台不认识的字段；
   由文件名 / 修改时间**推导**出来的日期、分类也不会被顺手写进文件
4. **正文里的空行原样保留** —— 「打开再保存」不会悄悄吃掉空行

### 顺手修掉的一个坑

Obsidian 有时候会把布尔值写成带引号的字符串：`pinned: "true"`。
你站点里判断的是 `pinned === true`，所以**这种情况下「置顶」会静默失效**。
后台读出来时会把它认成真布尔，保存时规范成 `pinned: true`，置顶就正常了。

## 调试开关

| 环境变量 | 作用 |
| --- | --- |
| `ADMIN_PORT=4322` | 换端口 |
| `ADMIN_ROOT=<路径>` | 把后台指向另一个项目目录（测试用） |
| `ADMIN_DEV_NOAUTH=1` | 跳过登录。**只在请求来自本机时生效**，云端误设也不会放行 |

## 测试

```bash
npm run admin:test       # 单元测试：frontmatter、保真、路径安全（20 项）
npm run admin:test:api   # 接口测试：在系统临时目录里跑完整后端（16 项）
```

接口测试会把需要的文件**复制到系统临时目录**，在沙盒里起一个随机端口的后台实例，
把所有写入接口跑一遍 —— **你真实的笔记、照片、配置一个字都不会被碰到**。

## 目录结构

```
admin/
├─ server/
│  ├─ admin-server.mjs    本地服务：鉴权、接口、静态文件、Markdown 预览、构建调度
│  ├─ file-store.mjs      笔记：frontmatter 解析/生成、读写、备份、路径白名单
│  └─ js-data.mjs         数据文件：安全地改 .js（注释/排版不动、语法检查）
├─ tests/
│  ├─ unit.test.mjs       单元测试
│  └─ api.test.mjs        接口测试（沙盒）
└─ README.md              本文件

public/admin/
├─ index.html             界面骨架
├─ admin.css              样式（深蓝 + 玫红，跟站点一套）

```

`.admin/` 是后台自己的数据（密码、备份），**不进 git**。

## 已知限制

- **只能在这台电脑上用。** 想在手机上改内容，需要把它搬到云端（见下）
- **构建需要项目装过依赖。** 如果 `npm run admin` 里的「构建」报 `astro 不是内部或外部命令`，
  说明还没跑过 `npm install`
- **抓视频封面需要联网**，而且抖音那条得靠你本机的浏览器 —— 后台可以先把链接和标题存下来，
  封面等你跑 `npm run sync:covers` 时补上
- 界面上暂时改不了 `config.js` 里的**对象数组**（首页章节条、社交链接、竖排导航）。
  那三块用表单改容易出错，直接编辑文件更稳，后台不会覆盖它们

## 下一步：搬到云端（手机也能用）

现在这套是**本地版**。云端版的计划：

1. 界面原样搬到 **EdgeOne Pages** 托管（你的 GitHub 仓库接上它就行）
2. 在 `node-functions/` 里写同样的接口，把数据层从「读写本地文件」换成「调 GitHub API 提交」
3. 密码改成环境变量里的哈希 + 签名 Cookie
4. 手机上打开 `admin.你的域名` 就能改内容，保存后 EdgeOne 自动重新构建上线

数据层的函数都是「路径由调用方传入」的写法，所以换存储后端不需要重写界面逻辑。
