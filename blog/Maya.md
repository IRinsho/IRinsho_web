### 🛠️ 基础工具与操作

这些是使用频率最高的基础快捷键，建议优先掌握[](https://help.autodesk.com/cloudhelp/2025/CHS/Maya-KeyboardShortcuts/files/GUID-30CACC9D-8FBE-4B85-8A8F-C5ADF32DDD4E.htm)。

| 快捷键          | 功能      |
| ------------ | ------- |
| **Q**        | 选择工具    |
| **W**        | 移动工具    |
| **E**        | 旋转工具    |
| **R**        | 缩放工具    |
| **Ctrl + Z** | 撤销      |
| **Ctrl + Y** | 重做      |
| **G**        | 重复上一次操作 |
| **Ctrl + D** | 复制对象    |
| **F**        | 框显当前选择  |
| **A**        | 框显全部    |

### 🎯 选择模式与组件切换

快速在对象和不同的组件（点、线、面）模式间切换，是建模流畅度的关键。

|快捷键|功能|
|---|---|
|**F8**|在**对象模式**和**组件模式**间切换|
|**F9**|进入**顶点**选择模式|
|**F10**|进入**边**选择模式|
|**F11**|进入**面**选择模式|
|**Ctrl + F9/F10/F11**|将当前多边形选择转化为顶点/边/面|

### ⚡ 核心建模操作

这些快捷键直接对应建模命令，能显著加快操作速度。

|快捷键|功能|备注|
|---|---|---|
|**Ctrl + E**|**挤出**（Extrude）|选中面或边后使用|
|**Ctrl + B**|**倒角**（Bevel）|用于边或面|
|**Ctrl + Shift + R**|**插入循环边**（Insert Edge Loop）|在多边形上添加循环边|
|**M**|**合并顶点**（Merge Vertex）|在顶点模式下使用|
|**Shift + 右键**|打开**建模标记菜单**|可快速访问挤出、倒角、合并、插入循环边等常用命令|

### 🖱️ 视图导航与显示

熟练控制视图是3D建模的基础，这些操作主要依靠 `Alt` 键配合鼠标完成。

|操作|功能|
|---|---|
|**Alt + 左键拖动**|旋转/翻滚视图|
|**Alt + 中键拖动**|平移视图|
|**Alt + 右键拖动**|缩放/推拉视图|
|**空格键**|切换单视图/四视图模式|

在显示模式方面，**数字键 1-7** 可以快速切换不同的着色和显示质量，例如按 **4** 显示线框，按 **5** 显示着色，按 **6** 显示带纹理的着色。

### 💡 实用技巧

- **重复操作**：完成一次挤出后，使用 **G** 键可以重复该操作，非常适合制作阶梯或重复的结构。
    
- **自定义快捷键**：如果某些命令没有默认快捷键，你可以在 **窗口 > 设置/首选项 > 热键编辑器** 中根据自己的习惯进行设置。
