# 商品打折问题
### 问题：小明到商店买圆珠笔，每只圆珠笔的价格是3元，但近期商店开展打折促销活动，如果购买圆珠笔的数量超过20支，则超过20只的部分价格下调为每支2元。

请编写程序，输入购买圆珠笔的数量，输出小明需要支付的金额（单位：元）。
```c
#include <stdio.h>  
#include <math.h>  
int main() {  
    int ball_point_pen_of_amount;//圆珠笔的数量  
  
    scanf("%d",&ball_point_pen_of_amount);  
    if (ball_point_pen_of_amount >= 20) {  
        int out_of_range;//超出的数量  
        out_of_range = ball_point_pen_of_amount - 20;  
        int payment_amount;//支付金额  
        payment_amount = (20*3)+(out_of_range*2);  
        printf("%d",payment_amount);  
    }  
    else {  
        int payment_amount;  
        payment_amount = ball_point_pen_of_amount*3;  
        printf("%d",payment_amount);  
    }  
    return 0;  
}
```

# 阶乘和
```c
#include <stdio.h>  
#include <math.h>  
int main() {  
    int n;  
    long long sum=0;  
    long long factorial=1;  
    scanf("%d",&n);  
        for (int i=1; i<=n; i++)  
        {  
            factorial*=i;  
            if (i%2==0) sum -= factorial;  
            else sum += factorial;  
  
        }  
         printf("%lld ",sum);  
}
```
