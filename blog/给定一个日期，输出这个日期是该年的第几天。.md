# 代码
```c
#include <stdio.h>
#include <math.h>
int main() {
    int month,year,day;
    int days_in_month[13]={0,31,28,31,30,31,30,31,31,30,31,30,31};
    while(scanf("%d-%d-%d",&year,&month,&day)!=EOF) {
        int sum_days = 0;
        if (year%4==0 && year%100!=0 || year%400==0){
            days_in_month[2]=29;
        }
        else
            ;
        for (int i = 1; i < month; i++) {
            sum_days += days_in_month[i];
        }
        sum_days += day;
        printf("%d",sum_days);
    }
    return 0;


}
```
## 拆解
### `int days_in_month[13]={0,31,28,31,30,31,30,31,31,30,31,30,31};`
- 定义一个名为**days_in_month**的一维数组。
### `while(scanf("%d-%d-%d",&year,&month,&day)!=EOF)`
- 判断输入。
### 循环体
```c
