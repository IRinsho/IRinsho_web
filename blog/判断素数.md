# 代码
```c
#include <stdio.h>  
#include <math.h>  
  
int main() {  
    int prime_number;  
    int count=0;  
    int is_prime[100];  
    for (prime_number = 100; prime_number < 200; prime_number++) {  
        int flag = 1;//是素数  
        for (int d = 2; d <= sqrt(prime_number); d++) {  
            int c = prime_number % d;  
            if (c == 0) {  
                flag = 0;//不是素数  
                break;  
            }  
        }  
        if (flag == 1) {  
            is_prime[count++] = prime_number;  
        }  
    }  
    printf("%d\n", count);  
    for (int i = 0; i < count; i++) {  
        printf("%d ", is_prime[i]);  
    }  
}
```
# 思路拆解
* ```c
	int prime_number;  
	int count=0;  
    int is_prime[100]; 
  ```
   1. `int prime_number`定义一个整形变量名为：素数
   2. `int count=0`定义计数器初始量为0
   3. `int is_prime[100]`定义一个名为“是素数”的数组
* ```c
  for (prime_number = 100; prime_number < 200; prime_number++) {  
        int flag = 1;//是素数  
        for (int d = 2; d <= sqrt(prime_number); d++) {  
            int c = prime_number % d;  
            if (c == 0) {  
                flag = 0;//不是素数  
                break;  
            }  
        }  
        if (flag == 1) {  
            is_prime[count++] = prime_number;  
        }  
    }  
  ```
  1. 这是判断是否为素数的循环主要部分
  2. ```c
     if (flag == 1) {  
            is_prime[count++] = prime_number;  
        } 
     ```
     如果是素数（``flag == 1``）那么将素数（``prime_number``）写入is_prime的数组，然后``count++``进行一次计数。
* 最后的输出环节
  ```c
    printf("%d\n", count);  
    for (int i = 0; i < count; i++) {  
        printf("%d ", is_prime[i]);  
    } 
  ```
  1. ``printf("%d\n", count);``输出次数
  2. ```c
     for (int i = 0; i < count; i++) {  
        printf("%d ", is_prime[i]);  
    } 
     ```
     输出寄存在is_prime数组里面的每一位上的素数。
